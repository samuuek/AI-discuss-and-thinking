# 思屿使用指导

最后核验：2026-08-21

## 1. 最快开始使用

1. 双击桌面的“思屿”快捷方式，或打开 <https://temporary-prompt-ridge-2fk9bxn.vercel.app/#today>。
2. 第一次在一台设备上打开时，输入“私人访问口令”，然后点击“进入思屿”。
3. 口令验证成功后会保存在该浏览器本地；清理浏览器数据、使用无痕窗口或更换设备后需要重新输入。
4. 其他电脑和手机使用同一个网站与同一个口令，看到的是 Neon 中的同一份议题、思考空间、对话、周报和知识库数据。

口令不写在本文件里。本机开发工作树的 `.env.local` 保存了对应变量，Vercel 的 Production 和 Preview 环境也保存了 Sensitive 副本。读取或轮换时只处理 `SIYU_PRIVATE_ACCESS_TOKEN`，不要截图、打印或上传变量值。Vercel 的 Sensitive 值不能回显；如果本地副本丢失，需要生成新口令、同时轮换两个环境，再创建新部署。

## 2. 网页主要功能

- **今日**：查看每天议题、创建自己的议题并进入思考。
- **思考**：保存观点、旁注、对话和纪要，刷新后仍由云数据库保留。
- **AI 周报**：读取最近 7 天官方 AI 动态，并可把材料交给外部网页模型分析。
- **知识库**：搜索议题、纪要、感思和对话。
- **回顾**：回看已经沉淀的内容。

DeepSeek、通义千问、Kimi 等“免费网页版”入口只负责复制提示词并打开官方网页。思屿不会读取这些平台的账号、密码或登录状态；回答完成后需把结果粘贴回思屿保存。

### 在网站中配置 DeepSeek API

1. 点击网页右上角“服务”，展开“API 高级配置”。
2. 在 DeepSeek API 区域粘贴 Key，先点“测试连接”。测试只读取模型列表，不生成对话。
3. 选择测试返回的模型，点击“保存配置”。输入框会立即清空，之后同一网站的其他已授权设备也可使用该模型。
4. 不再使用时点击“停用并删除网站配置”。停用状态会阻止旧环境变量自动恢复 DeepSeek。

网站不会回显已保存的 Key。若显示“需要重新填写”，说明凭据主密钥发生变化或密文已损坏，需要重新输入。模型 API 可能由 DeepSeek 收费，与免费网页版入口不是同一项服务。

## 3. 微信小程序

### 导入和预览

1. 安装并登录微信开发者工具。
2. 导入当前源码中的 `miniapp` 目录。正式 AppID 已保存在 `miniapp/project.config.json`，无需在说明文档中重复填写。
3. 在 `miniapp` 目录运行 `npm install`，再运行 `npm run build:weapp`；开发时可运行 `npm run dev:weapp`。
4. 开发者工具中点击“预览”，用安卓手机微信扫码。

### 微信云开发必须项

1. 在微信开发者工具中打开“云开发”，创建或选择免费环境。
2. 部署 `miniapp/cloudfunctions/siyuApi`，选择“云端安装依赖”。
3. 给云函数配置两个加密环境变量：
   - `SIYU_WEB_API_BASE_URL`：生产网站地址。
   - `SIYU_PRIVATE_ACCESS_TOKEN`：与 Vercel Production 相同的私人访问口令。
4. 重新部署云函数并重新预览小程序。

小程序本身不要求输入网页版口令。它通过微信云函数访问同一个 Vercel API 和 Neon 数据库，因此网页与小程序可以同步。首次成功访问云函数的微信账号会锁定为私人空间的唯一账号；不要用临时账号先完成首次访问。

## 4. 常见故障

### 网页提示口令不正确

- 确认使用的是最近一次轮换后的口令。
- Vercel 中 Production 和 Preview 是两条独立变量，需要写入同一个值。
- 轮换后必须创建新 Git 源码部署；旧部署不会自动生效。
- 访问 `/api/health` 应返回数据库 `ready`，使用正确口令访问 `/api/models` 应返回 HTTP 200。

### 小程序提示 `request:fail timeout`

- 确认微信云开发环境已创建。
- 确认 `siyuApi` 云函数已经部署，而不只是存在于本地。
- 确认云函数的两个加密环境变量已配置并重新部署。
- 检查手机微信账号是否为这个私人空间首次绑定的账号。

### Preview 地址打不开

Preview 部署受 Vercel 登录保护，需要先登录拥有该项目权限的 Vercel 账号。日常使用请打开固定 Production 地址。

### 中国网络访问不稳定

当前使用 Vercel 免费域名，没有中国大陆备案和可用性承诺。网络偶发失败时可重试或更换网络；微信小程序优先通过微信云开发访问服务端，但共享数据仍依赖 Vercel 与 Neon。

## 5. 备份与归档

- 本地总归档：`D:\AI思屿`
- 当前源码：`D:\AI思屿\01-当前源码`
- 历史小程序包：`D:\AI思屿\02-微信小程序历史包`
- 使用和接续文档：`D:\AI思屿\00-文档`
- GitHub：<https://github.com/samuuek/AI-discuss-and-thinking>

创建新的安全小程序 ZIP：

```powershell
cd miniapp
npm run archive -- "D:\AI思屿\02-微信小程序历史包\思屿日记-微信小程序-新归档.zip"
```

归档脚本会排除本地密钥、凭据主密钥、模型 API Key、`node_modules`、缓存、旧 ZIP 和私有微信配置。网页导出的数据备份也不包含模型凭据；数据库备份应使用 Neon 分支或备份功能，不能只复制网页源码。
