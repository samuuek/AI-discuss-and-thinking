# 思屿微信小程序验证记录

日期：2026-08-19

## 已验证范围

- Taro 4.2.1 微信目标可成功编译，输出包含五个底部入口和思考空间详情页。
- 今日页面读取并去重每日议题，支持创建私人议题。
- 思考空间读取和保存对话、旁注、纪要、感思与资料。
- DeepSeek 流程支持复制问题、返回小程序、读取剪贴板、编辑和保存回答。
- AI 周报读取官方内容，优先显示已保存中文译文，并支持刷新和翻译导入。
- 知识库可搜索个人内容，回顾页按日期倒序分组。
- 网站与小程序 API 支持同一私人访问口令；健康检查不暴露口令。
- 小程序源码安全测试会拒绝数据库连接串、带值的敏感环境变量和硬编码访问头。

## 自动验证

- 网站测试、类型检查、生产构建。
- 小程序测试、类型检查、微信代码构建。
- Git 跟踪文件与小程序源码敏感信息扫描。

## 仍需用户完成

- 安装微信开发者工具并导入 `miniapp` 目录。
- 用安卓微信扫描测试预览二维码。
- 正式 AppID 获得后替换测试 AppID，并在微信公众平台配置 Vercel HTTPS 请求域名。
