# 思屿微信小程序设计

## 目标

为“思屿”增加一个仅供用户本人使用的微信小程序客户端。第一阶段使用测试 AppID，在安卓手机上预览；正式 AppID 获得后可替换配置并继续完善微信登录。小程序与现有网站共用 Vercel API 和 Neon 数据库，网页与手机内容保持同步。

## 范围

第一版包含五个主要入口：今日、思考空间、AI 周报、知识库、回顾。它们覆盖当前网站的核心浏览、创建、编辑和保存流程，并延续现有中文界面与视觉风格。

第一版不包含多人注册、公开分享、付费资源、自定义域名，也不在小程序中直接调用收费 AI API。正式 AppID、微信身份登录和多用户数据隔离属于后续阶段。

## 技术方案

在现有仓库中新增独立的 `miniapp` 工程，使用 Taro、React 和 TypeScript，编译目标为微信小程序。网站工程保持独立，避免小程序构建配置影响现有 Vite/Vercel 部署。

小程序只调用 HTTPS API，不直接连接 Neon。数据库连接串和服务端密钥继续只保存在 Vercel 环境变量中。客户端只保存测试阶段的私人访问凭证和非敏感界面状态，相关本地配置必须被 Git 忽略。

## 页面与交互

底部导航包含“今日、思考、周报、知识库、回顾”。界面采用米白背景、墨绿色强调色、中文标题和适合手机触控的卡片布局。

- 今日：显示真实日期、每日三个议题，并支持创建和打开议题。
- 思考空间：显示议题对话、私人旁注、纪要与感思，支持继续编辑并保存。
- AI 周报：读取官方信息和已保存的中文译文，支持刷新与导入分析。
- 知识库：浏览和搜索已保存的纪要、感思、对话与资料。
- 回顾：按时间查看个人思考记录和使用情况。

所有页面提供加载中、空状态、失败提示和重试入口，避免网络异常时出现空白页面。未保存的输入在失败后保留。

## DeepSeek 往返流程

微信小程序不能可靠地随意打开外部网页，也不能读取 DeepSeek 的账号或页面内容，因此保留人工确认的安全流程：小程序生成并复制提示词；用户切换到已登录的 DeepSeek；复制回答；回到小程序读取剪贴板、预览和编辑；确认后保存到当前议题或周报。

如果剪贴板读取被拒绝，界面提供手动粘贴。小程序不会收集或保存 DeepSeek 的账号、密码、Cookie 或登录状态。

## 数据与访问控制

第一阶段仅供用户本人使用。API 增加一层私人访问校验，小程序在请求中携带本地保存的测试凭证。凭证不写入源代码、不提交 GitHub，也不出现在日志中。

测试 AppID 阶段不建立正式的微信身份映射。正式 AppID 就绪后，以微信登录换取服务端会话，并将数据访问约束到对应用户；这项升级不得破坏现有单人数据。

## API 与兼容性

优先复用现有 API。若浏览器专用接口与小程序请求方式不兼容，仅增加薄适配层，不复制业务逻辑。Vercel 必须允许小程序所需的 HTTPS 请求；正式发布前需在微信公众平台配置合法 request 域名。

现有网站继续工作。数据库结构变更必须向后兼容，并通过服务端迁移完成。

## 错误处理与隐私

请求超时或断网时显示中文原因和重试按钮；创建或保存操作使用明确的进行中状态，避免重复提交。返回登录失效时提示重新配置私人访问，而不显示凭证内容。

禁止提交或输出 `DATABASE_URL`、`.env`、`.env.local`、`data`、`.vercel`、`exports`、`output` 及小程序私人配置。不得在小程序包中包含数据库连接串或第三方密钥。

## 验证与完成标准

- 小程序工程可以使用测试 AppID 编译并在微信开发者工具中打开。
- 五个主要页面可访问，中文文案和移动布局无明显溢出。
- 健康检查通过，首页和周报能读取现有线上数据。
- 创建议题、保存对话或编辑内容后，刷新小程序和网站仍能看到相同数据。
- DeepSeek 复制、返回、粘贴、预览和保存流程可完成。
- 网络失败、剪贴板拒绝和空数据均有可恢复的中文提示。
- 仓库和构建产物中不存在环境文件、数据库连接串或私人访问凭证。

## 后续阶段

正式 AppID 获得后，替换测试配置，配置合法请求域名，接入微信登录和服务端会话，再根据实际发布要求处理隐私说明、体验版和审核材料。多人使用只有在完成用户级数据隔离后才能开放。
