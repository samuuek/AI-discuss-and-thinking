# 思屿微信云开发后端设计

## 背景与目标

安卓真机中的微信小程序访问 `*.vercel.app` 时持续超时，而同一接口在电脑和微信模拟器中正常。小程序改为通过微信云开发调用云函数和云数据库，避免真机直接连接 Vercel，同时保留现有网站和 Neon 部署。

第一目标是让用户本人能够在微信预览版中稳定使用“今日、思考、周报、知识库、回顾”，创建的议题、对话、旁注、纪要、感思和周报译文在小程序重新打开后仍然存在。

## 范围与约束

- 使用正式 AppID `wxb652ab7130eb1b4a` 绑定的微信云开发免费体验环境。
- 不开启按量付费、不购买套餐、不创建自定义域名。
- 云函数使用微信身份 `OPENID`；第一个成功访问者自动成为唯一所有者，其他微信账号不能读取或修改数据。
- 小程序不再保存私人访问口令，也不再直接请求 Vercel。
- 网站继续使用现有 Vercel 与 Neon，不因本次迁移停止服务。
- DeepSeek 继续采用复制提示、切换账号、复制回答、回到小程序保存的人工流程；不读取账号、密码、Cookie 或登录状态。
- 每日三个议题由内置中文思想题库按上海日期稳定生成，不调用付费 AI API。
- 周报刷新由云函数读取官方公开来源；单个来源失败时保留其他成功来源和已有内容。
- 不提交或打印 `.env`、`.env.local`、`DATABASE_URL`、访问口令、云端票据或用户 `OPENID`。

## 架构

`miniapp/src/api/client.ts` 通过 `Taro.cloud.callFunction` 调用单一云函数 `siyuApi`。云函数将动作分派给纯业务服务，再由 CloudBase 数据库仓库读写一个 `siyu_state` 集合。

集合使用固定文档类型：所有者、议题、思考空间和周报状态。思考空间文档包含消息数组，适合当前单用户规模；每次写入均更新时间。云函数返回统一的 `{ ok, data }` 或 `{ ok: false, error, code }`，客户端转换成现有页面所需的类型和中文错误。

云开发环境 ID 只写入小程序公开运行配置；它不是密钥。云函数使用 `wx-server-sdk` 的当前环境，不包含数据库连接串。

## 完成标准

- 云函数核心、客户端传输和每日议题均有先失败后通过的自动化测试。
- 小程序不再引用 Vercel API 或私人访问口令。
- 云开发免费环境处于可用状态，`siyuApi` 部署成功，`siyu_state` 集合存在。
- 安卓真机扫描新预览码后可打开首页，不出现连接超时。
- 创建议题、刷新、重新打开后议题仍存在；对话和四类笔记可保存。
- 周报页面能显示已有或刚刷新的官方信息，并能保存中文译文。
- 全部小程序测试、类型检查、微信构建和敏感信息扫描通过。
